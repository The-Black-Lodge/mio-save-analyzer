# MIO: Memories in Orbit Save Parser

Parses your save file and determines what you're missing. Includes some links to help you find your way.

- Datamined textures are available here: [mio-extracted-textures](https://github.com/MIO-Modding/extracted-textures/tree/main)
- Datamining scripts are available here: [mio-data-mining](https://github.com/The-Black-Lodge/mio-data-mining)
- Decompile tool is available here: [mio-decomp-cli](https://github.com/MIO-Modding/mio-decomp-cli)
